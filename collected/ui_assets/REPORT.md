## 使用说明

小图标的描边使用 `currentColor`。预览使用独立 `<img>` 加载 SVG，墨蓝栏通过 CSS 把图标图像示为白色。系统把 SVG 内联到按钮或标签中时可直接继承文字颜色。插画保留透明画布，卡片、文书和盾牌带暖白及白色填充，在两种底上均可辨认。网纹与白版印章在纸色底上对比低，墨蓝水印在墨蓝底上会融入底色，预览保留这两组底色以供对照。

墨蓝水印在 SVG 图层内设置 5% 透明度，与 Streamlit 直接把 SVG 用作背景图的方式匹配。
