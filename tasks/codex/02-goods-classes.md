# 任务 02：补全区分表第 29、30、32、43 类的商品项

先读 [README.md](README.md) 里的通用规则。

## 背景

系统判断“商品是否类似”时，要把双方的商品对应到《类似商品和服务区分表》的具体商品项。现有的商品项库 `data/goods/goods_items.xlsx` 只选录了 143 项（第 29 类只收了与饮料有关的项目，第 43 类只收了餐饮相关项目），查不到的商品只能标“待核实”。

请把这四个类别的商品项补全，并照录每个类似群的注释。

## 要做什么

1. 找到当前有效版本的《类似商品和服务区分表》官方文本（国家知识产权局发布）。在 `REPORT.md` 里写明版本名称、发布日期、文件来源网址；如果同时存在新旧版本，用现行版本，并说明依据。
2. 把第 29、30、32、43 类的**全部**商品项照录出来。
3. 把这四个类别里每个类似群的**注释原文**照录出来（例如“本类似群与 3202 类似”“本类似群各部分之间商品不类似”这类说明），包括跨类的关联说明。

## 输出格式

一个 Excel 文件 `collected/goods/goods_items_full.xlsx`，两个工作表，列名和现有文件保持一致，方便直接替换：

**工作表“商品项库”**

| 列 | 说明 |
| --- | --- |
| 商品项编号 | 原文照录，含前缀字母（如 `C300146`） |
| 规范名称 | 原文照录，保留星号等标记 |
| 类别 | 整数 |
| 群组 | 四位类似群号，如 `3002` |
| 部分 | 群内分部分时填“（一）”“（二）”，否则留空 |
| 页码 | 该项在官方文本中的页码 |

**工作表“群组注释”**

| 列 | 说明 |
| --- | --- |
| 群组 | 四位类似群号 |
| 注释序号 | 原文中的编号，如 `注1` |
| 注释原文 | 一字不改照录 |
| 页码 | 页码 |

注意：

- 现有文件里“关联注释”工作表（R01–R10、H01–H09）是人工把注释整理成规则后的结果，**这次不需要做这种整理**，只照录原文。整理成规则由我们来做。
- 同一编号对应多个名称的情况是存在的（例如一个编号下有两个并列名称），各占一行，不要合并。
- 不要补充官方文本里没有的商品。

## 交付

- `collected/goods/goods_items_full.xlsx`
- `collected/goods/REPORT.md`：除通用规则要求的内容外，写明每个类别的商品项数和类似群数，以及与现有 `data/goods/goods_items.xlsx` 对比，有哪些编号或名称不一致。
