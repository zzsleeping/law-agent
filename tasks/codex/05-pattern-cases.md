# 任务 05：按比对情形补充商标评审文书（第三批）

先读 [README.md](README.md) 里的通用规则。JSON 格式与 [01-decisions.md](01-decisions.md) 相同，
无效宣告、不予注册复审的字段对应见 [04-more-decisions.md](04-more-decisions.md)，校验脚本也相同。

## 为什么要第三批

前两批 152 份文书已经入库，用途有两个：报告里附“同类情形的参考判例”（近似、不近似各给一两件），
以及评测大模型判定时参考判例能否提高准确度。按比对情形统计（`python scripts/pattern_coverage.py`），
现有数据的问题是**官方认定“不近似”、且两边共用汉字的商标对太少，而且集中在少数文书里**：

| 比对情形 | 例子 | 现有 近似 | 现有 不近似 |
| --- | --- | ---: | ---: |
| 完整包含 | 茗悦 / 茗悦泉 | 69 对（52 份） | **5 对（5 份）** |
| 共用部分 | 温氏鲜行 / 温氏集团 | 108 对（54 份） | 17 对（7 份） |
| 仅一字不同 | 花言花语 / 花言巧语 | 45 对（33 份） | **0** |
| 字序颠倒 | 美亚 / 亚美 | 14 对（8 份） | **1 对** |
| 叠字 | 乐乐 / 乐 | 1 对 | **0** |
| 读音相同或相近 | 古茗 / 古名 | 11 对（8 份） | **1 对** |
| 字形相近 | 喜茶 / 嘉茶 | 0 | **0** |

另有 46 对“不近似”两边一个汉字都不共用，系统不会把它们当作候选，对评测和参考都没有用。

## 要找什么

**本批新增的配额**（用 `--since` 只统计本批，见下文“自检”）：

| 比对情形 | 近似 至少 | 不近似 至少 | 说明 |
| --- | ---: | ---: | --- |
| 完整包含 | — | 30 对，来自 ≥15 份文书 | 例如多出的部分改变了整体含义、原商标是常用词或显著性弱 |
| 共用部分 | — | 40 对，来自 ≥20 份文书 | 例如共用的是通用词、描述性词汇，或其余部分使含义明显不同 |
| 仅一字不同 | — | 10 对 | 例如换的那个字使含义完全不同 |
| 字序颠倒 | 10 对 | 8 对 | |
| 叠字 | 5 对 | 5 对 | 例如“乐乐 / 乐”“甜甜圈 / 甜圈” |
| 读音相同或相近 | 10 对 | 10 对 | 例如读音相同但字形、含义差别明显 |
| 字形相近 | 10 对 | 5 对 | 例如只差一两个笔画或部件的“山寨”商标 |

- **配额是下限，不要为了凑数降低标准**。有的情形（如叠字、仅一字不同的“不近似”）官方文书本来就少，
  尽力查找后仍不够的，如实在报告里写明查了哪些检索词、看了多少份，不要把不属于该情形的商标对硬算进去。
- **比对情形以脚本的判断为准**，不以你的理解为准。可以用 `--list 情形名` 查看脚本把哪些商标对归到了哪一类。
- **分散来源**：同一份文书里，同名的引证商标（文字相同、注册号不同）最多记 2 件，并在 `notes` 写“同名引证已节选”；
  一份文书对任何一个情形的贡献不超过 3 对。上一批 58 对“难反例”实际只有 35 组不同的名称，这次要避免。
- **不要重复**：按文书编号和申请号与 `collected/decisions/` 已有的 152 份查重。

## 认定理由要摘到点子上（本批的重点）

报告里会把判例的认定理由展示给用户，所以 `reasoning_excerpt` 要摘录**为什么**近似或不近似的那一句，而不是只有结论：

- 好的摘录：“‘燊海’为臆造词，显著性强，与‘徐记’组合后整体含义与引证商标区别明显”
- 不够的摘录：“未构成近似商标”“文字构成、呼叫等方面相近”

原文照录，不改写；不超过 100 字（校验脚本的上限）。原文确实只有结论、没有理由的，照录结论，并在 `notes` 写“原文未述理由”。

## 类别

- 优先第 29、30、32、43 类（正式商标库只覆盖这四类，这些文书还能用来测召回）。
- 字序颠倒、叠字、仅一字不同、读音相同或相近、字形相近这五种情形的商标对，**可以放宽到其他类别**，
  因为标识是否近似的判断与类别关系不大。放宽类别的文书在每件引证的 `notes` 里写“非目标类别”，
  `goods` 照常按原文填写类别。

## 来源和检索

- 来源要求与任务 04 相同：国家知识产权局官方文书原文，或保留官方文书编号的全文转载（如标库网）；
  公开可访问的商标行政诉讼判决书也可以，`doc_type` 如实填写。代理机构文章、案例点评、摘要不能作为来源。
- 检索词可以参考：“不构成近似商标”“未构成使用在同一种或类似商品上的近似商标”“整体含义”“显著部分”“字序”
  “叠字”“呼叫相同”“含义不同”，再加类别或商品名称。
- 遇到登录、验证码、访问限制，按通用规则停下报告（裁判文书网需要登录，不要使用）。

## 自检

```bash
python scripts/validate_collected.py
python scripts/pattern_coverage.py --since 本批开始日期
python scripts/pattern_coverage.py --since 本批开始日期 --list 完整包含
```

第一条没有报错（outcome 枚举的预期报错除外，见任务 04）；第二条用来对照上面的配额。
`retrieved_at` 填实际获取日期，`--since` 才能只统计本批。

## 交付

- `collected/decisions/*.json`（与前两批放在一起，文件名不重复）
- `collected/decisions/REPORT_batch3.md`，包括：
  1. 来源、检索词、看过多少份、收了多少份、跳过原因（同任务 04 的表格）；
  2. `pattern_coverage.py --since` 的输出，以及各情形与配额的差距、没达到的原因；
  3. 每个情形的“不近似”清单：文书编号（带链接）、两个商标、比对情形、认定理由摘录。
