# 任务 06：页面视觉素材（图标、插画、背景纹样）

先读 [README.md](README.md) 的通用规则。本任务不收集数据，第 2、3、5、6 条（来源追溯、原样记录、个人信息、
`validate_collected.py`）不适用；第 1 条（只写 `collected/`）和第 7 条（交付说明）照常适用。

## 背景

系统页面（Streamlit）正在改版，风格定为“**编辑式法律工作台**”：深墨蓝 + 暖白纸色，衬线标题，
细线条、留白多，只在品牌标识和关键处用一点印章红。参考的是 Harvey、CoCounsel 一类法律 AI 产品和
Corsearch / CompuMark 一类商标检索工具的共同特点：克制、可信、信息层级清楚，不用卡通、渐变霓虹、3D 或科技蓝光效。

需要你**用代码手写 SVG**（不要用位图生成工具，不要嵌入位图，不要依赖外部字体）。

## 硬性要求

1. **原创**：不得临摹或改画任何真实机构、法院、知识产权局、律所、商业产品的标志；不得出现国徽、法徽、警徽等标志；天平只画通用的简笔形态。
2. **SVG 规范**：设置 `viewBox`，不用 `<image>`、`<foreignObject>`、外部引用、`<script>`、滤镜和字体；路径尽量简洁（单个图标不超过 2 KB，插画不超过 40 KB）；用 Python 的 `xml.etree.ElementTree` 能解析通过。
3. **两种底色都能看**：浅色素材在纸色 `#f7f5f0` 上清楚，`-light` 版和纹样在墨蓝 `#0f1c2e` 上清楚。
4. **预览页**：写一个 `collected/ui_assets/preview.html`，把全部素材在纸色底和墨蓝底上各排一遍（直接用 `<img src="...">` 引用本目录文件），方便我们目视检查。
