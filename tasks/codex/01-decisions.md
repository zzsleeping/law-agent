# 任务 01：收集公开的商标驳回复审决定书

先读 [README.md](README.md) 里的通用规则。

## 背景

我们在做一个中文文字商标的近似风险筛查系统。需要一批**结论由官方做出**的真实案例，用来：

- 作为真实商标数据（替代目前的仿真数据）；
- 作为测试集：官方判定近似 / 不近似，用来检验系统判断对不对；
- 作为典型案例库，在报告里供参考。

驳回复审决定书正好满足：每份都写明申请商标、引证商标、各自的商品、日期，以及审理部门对“商标是否近似、商品是否类似”的结论。

## 要找什么

- **文书类型**：商标驳回复审决定书（国家知识产权局作出）。找不到足够的决定书时，可以补充商标驳回复审行政诉讼的判决书，在记录里标明 `doc_type`。
- **数量**：30–50 份。
- **商标类型**：选用双方为纯中文文字或以中文文字为主、图形部分不影响判断的商标对。每份入选文书至少有一件可核实的中文文字引证。纯图形、纯外文、纯数字及尚未核实标识的引证按编号留档，保留决定书已有结论，跳过文字评测。标识查不到时 `text` 填 `null`，在 `notes` 里说明来源和缺项。
- **类别优先**：第 29、30、32、43 类（茶、咖啡、饮料、乳制品、餐饮服务）。这几类不够 30 份时再放宽到其他类，记录照收。
- **结论平衡**：尽量让“维持驳回（认定近似）”和“初步审定 / 部分初审（认定不近似）”大致各占一半。不要只挑结论明显的案件。
- **时间**：2019 年及以后作出的决定优先。

## 来源

- 首选国家知识产权局官网公开的商标评审决定、裁定文书。具体入口请自行查找并在 `REPORT.md` 里写明。
- 法院判决可以用公开的裁判文书。需要登录才能查看的，按通用规则停下报告。
- 不要用商标代理机构的文章、博客、二手转述作为来源；它们可以帮你找到案号，但记录必须取自原文。

## 输出格式

每份文书一个 JSON 文件，放在 `collected/decisions/`，文件名用文书编号（把不能做文件名的字符换成 `-`）。

```json
{
  "doc_type": "驳回复审决定书",
  "doc_no": "文书编号，原文照录",
  "decision_date": "2024-05-20",
  "authority": "国家知识产权局",
  "source_url": "获取原文的网址",
  "retrieved_at": "2026-11-16",
  "applicant_mark": {
    "text": "申请商标文字",
    "app_no": "申请号",
    "app_date": "2023-01-10",
    "priority_date": null,
    "owner": "申请人名称；自然人写“自然人”",
    "goods": [
      {"name": "指定商品原文", "nice_class": 30, "group": "3002"}
    ]
  },
  "cited_marks": [
    {
      "text": "引证商标文字",
      "reg_no": "注册号或申请号",
      "app_date": "2018-03-02",
      "status": "文书中写明的状态，如“已注册”；没写就 null",
      "owner": "权利人名称；自然人写“自然人”",
      "goods": [
        {"name": "核定商品原文", "nice_class": 30, "group": "3002"}
      ],
      "mark_similar": "近似",
      "goods_similar": "类似",
      "reasoning_excerpt": "文书中关于这一引证商标的认定原文，100 字以内"
    }
  ],
  "outcome": "驳回 | 部分驳回 | 初步审定",
  "outcome_scope": "部分驳回时，写明哪些商品被驳回、哪些初审；否则 null",
  "notes": "任何需要说明的情况；没有就 null"
}
```

字段说明：

- `mark_similar`：只能是 `近似`、`不近似`、`未认定`（文书没有单独评价标识，例如只因商品不类似就判定不构成冲突）。
- `goods_similar`：只能是 `相同`、`类似`、`不类似`、`未认定`。
- 一份文书有多个引证商标时，`cited_marks` 里每个各占一项，分别记录结论；被撤销、无效等原因不再构成障碍的引证也要记，在 `notes` 里写明。
- 申请或引证商标的具体商品名称查不到时，保留商标记录，`goods` 填 `null`，并在 `notes` 里注明查阅来源和缺项。标识是否近似、商品是否类似按决定书有据可核的结论分别记录。仅因权利状态未参与实体比对且无相应结论的引证，相关结论填 `未认定`。商品明细缺失的记录不能用于逐项商品映射。
- `group`：文书没写类似群号就填 `null`，不要自己查区分表补。
- 日期一律 `YYYY-MM-DD`；只知道年月的填 `null`，在 `notes` 里写原文。
- 商品很多时可以只记与引证商标冲突相关的商品，并在 `notes` 里写“商品已节选”。

## 交付

- `collected/decisions/*.json`
- `collected/decisions/REPORT.md`：除通用规则要求的内容外，再给一张汇总表（文书编号、申请商标、引证商标、类别、标识结论、最终结果）。
